# Gung Ho: la fábula de la ardilla, el castor y el ganso

Infografía interactiva sobre el modelo Gung Ho de Ken Blanchard y Sheldon Bowles (1998): contexto, principios, aprendizajes, debilidades y referencias en APA 7.

Página estática (un solo `index.html`), lista para Cloudflare Pages sin comando de compilación.

## Infografía complementaria: Proyecto Aristóteles

En `aristoteles/index.html` está la infografía interactiva sobre el Proyecto Aristóteles de Google, la seguridad psicológica, la Googleyness y su relación con Gung Ho. En Cloudflare Pages se sirve en `/aristoteles/`.
